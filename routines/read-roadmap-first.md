# Read doctrine/ROADMAP.md before starting any flightdeck work

`doctrine/ROADMAP.md` is the file every flightdeck session reads first. It carries the
one invariant paragraph Aaron owns, the numbered R-id items with their status and proof,
what is deliberately out of scope, the dated decisions behind those choices, and the
Proposed section for anything the self loop finds that cites no R-id.

Read it before touching flightdeck source, before writing a brief for this repo, and
before treating a self-loop finding as work: a finding that names no R-id belongs under
Proposed, not in a brief, until Aaron promotes it. Every brief for this repo carries a
`roadmap: R-nn` line naming the item it serves.
